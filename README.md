# SkillGapPlatform

## Skill Gap & Employment Analytics Platform for Maharashtra

A web-based platform designed to help track skill development, employment outcomes and skill gaps of trained students.

## Key Features

- Student Registration and Login
- Student Profile Management
- Skills and Employment Status Tracking
- Government Officer Login
- Employment Statistics
- District-wise Analysis
- Training-wise Analysis
- Skill Gap Analysis
- Skill Recommendations
- Maharashtra Government Skill Gap Reference Data

## Technology Stack

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- SQLite
- REST API

## Data Source

Government reference data is based on the Maharashtra Skill Gap Analysis Report 2023.

## Project Purpose

The platform combines trainee-level information with skill-gap and employment analytics to support better monitoring of skilling outcomes and training requirements.

## Note

This is a prototype developed for demonstration and academic/SIH purposes. Production deployment would require verified government datasets, secure authentication, proper consent and privacy controls.
